# Protei Homeworks

Репозиторий для домашних заданий по практике.

- `task1` — C++ приложение с CMake, парсером аргументов командной строки и текстовым интерфейсом по командам.

## Ошибки и их критичность

### Критичные ошибки

Критичные ошибки приводят к немедленному завершению программы с ненулевым кодом возврата

- **Невалидный порт в командной строке**  
  - Пример: `-p abc`  

- **Невалидный ID в командной строке**  
  - Пример: `-i foo`  

- **Неизвестный или неполный флаг командной строки**  
  - Пример: `-x 123`, `-p` без значения.  

- **Ввод строки вместо числа в числовой вектор**  
  - Пример: `vector 1 2 a 4` при типе `int/double/float`.

- **Нулевое значение w-компоненты вектора**  
  - В данной реализации под w-компонентой понимается последний элемент вектора  
    (для размерности 1×1×1×4 — `arr[0][0][0][3]`).  

### Некритичные ошибки / предупреждения

Некритичные ситуации логируются, но не приводят к немедленному завершению программы:

- **Отсутствие аргументов командной строки**  
  - Программа стартует с дефолтными значениями:  
    `address = "127.0.0.1"`, `port = 0`, `role = "Client"`, `id = 0`, `library` пустая.  
  - В лог пишется `WARNING: no command line arguments provided; using defaults`.  

- **Неподдерживаемый тип вектора**  
  - Пример: `type long double`  

- **Команда с непечатными символами**  
  - Пример: бинарный мусор в строке команды.  


- **Неизвестная команда в меню**  
  - Пример: `abrakadabra`.  

### Общие замечания

- Все критичные ошибки командной строки приводят к исключению в `parseCommandLine` и перехватываются в `main`.
- Все ошибки пользовательского ввода в интерактивном режиме (меню) не приводят к аварийному завершению:
  - ошибка логируется,
  - пользователю выводится понятное сообщение,
  - программа продолжает работу, ожидая следующую команду.
